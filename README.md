# 花丸札

生活タスク用のGitHub Pages向けPWA。

普通のタスク管理ではなく、頭の中の札を剥がして、終わった札を花丸スタンプに変換するための小さい道具。

## MVP機能

- PWA化
- ローカル保存
- カテゴリ切替
- 単発／繰り返し登録
- 期限あり／いつでも
- いつでも札の表示数設定
- 今日のおすすめハイライト
- 完了タップ
- 花丸スタンプ変換
- 単発削除
- 繰り返しリセット
- 二重カウント防止
- 提出文生成
- Undo
- JSONエクスポート／インポート
- AI向け依頼文生成とタグ形式取り込み

## GitHub Pages

Repository settings → Pages → Deploy from a branch → `main` / `/root` を選ぶ。

## v16：定期札と月次札

- **定期（完了日から数える）**：完了を押した日の、指定した日・週・月・年数後に次回を出す。花丸への変換日は基準にしない。月・年の計算で同じ日が存在しない場合は月末を使う。
- **月次（毎月別の札）**：指定日以降に、その月の札を１枚ずつ発生させる。未完了の過去分を残して次月分を追加する。アプリを開いていなかった月も、次回表示時に補う。
- 月次の名前は月を含めず入力し、「当月分／前月分」と発生開始日を設定する。例：毎月５日・前月分なら、８月５日に「家計簿登録 2026年7月分」が出る。31日指定など、その日がない月は月末に出る。
- 同じ月次作業は折りたたんだ１枚として表示する。各月は個別に完了・花丸変換・削除できる。月次設定を編集すると未完了分と今後の札に反映し、完了済みの名前は維持する。
- 右上の花丸数 → 「月次札の設定」から発生を停止できる。再開時は今月から再開し、停止中の過去月は追加しない。停止・再開しても既存の札は残る。
- 既存の繰り返し札は定期札へ引き継ぐ。月次にしたい札は編集で切り替える。発生開始日を、引き継ぎたい古い札の発生月に合わせる。
- 既存の花丸・履歴・グループ・テンプレートは維持する。初回更新時のデータは `hanamaru-before-v16` にも保存する。旧版で完了日時が消えている場合は、残っている最後の花丸変換日時から次回を計算する。
- 次回発生時刻は設定の「日課リセット時刻」に従う。完了済みの札は次回日まで完了欄に残り、次回日を表示する。次回日まで花丸変換しなかった完了札も、別の完了札として保持する。
